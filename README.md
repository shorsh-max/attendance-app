# Attendance App (React + TypeScript + Tailwind + Supabase)

This is a starter attendance app.

Setup
1. Create a Supabase project (you already have one).
2. Run the SQL in supabase/setup.sql in your Supabase SQL editor to create the attendance table.
3. Create an .env file at the project root with:

VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_anon_key

4. Install and run:

npm install
npm run dev
